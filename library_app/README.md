# Library App

一个用于练习 Python 后端基础的迷你图书馆项目。

## 已练习内容

* Python 函数与类型注解
* HTTP API 请求
* JSON 数据解析与保存
* 异常处理
* httpx
* async / await
* asyncio.gather 并发请求
* Git 基本操作

## 项目结构

* `main.py`：程序入口
* `models/`：数据模型
* `services/`：业务逻辑和 API 调用
* `utils/`：工具函数
* `async_*.py`：异步编程练习
* `api_client.py`：API 请求、异常处理和 JSON 保存练习

## 运行

```bash
uv run main.py
```
